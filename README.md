### What I do

- 🔬 Build **agentic DS systems** that automate end-to-end product analytics workflows: metric decomposition, anomaly detection, experiment analysis, PM-ready narratives
- 📊 Design and analyze **A/B tests** at scale: CUPED variance reduction, SPRT sequential testing, O'Brien-Fleming boundaries, HTE subgroup analysis
- 📈 Apply **causal inference** to real product questions: IV/2SLS, DiD, RDD, propensity score methods on observational data
- 🎯 Build **ranking and recommendation systems**: two-stage retrieval and scoring pipelines with position bias correction and auction mechanics
- 🤖 Ship **LLM pipelines** end to end: RAG, agentic workflows, LangGraph, AWS Bedeck, Groq
- ⚙️ Design **end-to-end ML systems**: data pipelines, feature stores, model training, evaluation harnesses, serving, and monitoring in production
- 💬 Talk to me about experiment design, metric frameworks, causal inference, and production ML systems

Experiment design · Metric decomposition · Causal inference (IV, 2SLS, DiD, RDD) · LLM pipelines · Agentic workflows · End-to-end ML system design · A/B testing at scale
